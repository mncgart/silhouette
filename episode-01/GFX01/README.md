# GFX 01 — لجنة أميركا أولًا ← 1940–1941

نفس ستايل المرجع (Gfx-S1): كولاج أرشيفي أبيض وأسود فوق ورق جرايد، صور مطبوعة ببرواز أبيض، أحمر `#B11D24` للعناوين، ورق ممزّق، فلاش نيجاتيف، سنة كبيرة بتلف أرقامها زي العدّاد، كاميرا 3D بتدفع ببطء، جرين وفليكر.

## التشغيل في After Effects
1. نزّل الأصول من ملف الـ Asset Sheet وحطها في فولدر `GFX01_assets` جنب السكربت بالأسماء دي (أي امتداد jpg/png/tif/psd):
   - `GFX01_AFC_Poster` — ملصق لجنة أميركا أولًا (USHMM)
   - `GFX01_Lindbergh_AFC_Platform` — ليندبرغ على المنصة (LOC 94506130)
   - `GFX01_Lindbergh_Crowd` — الحشد (LOC 2003668307)
   - `GFX01_Newspaper_Texture` — اختياري: صفحة جرنال حقيقية للخلفية (من غيرها السكربت بيعمل خلفية جرايد بنفسه)
2. نصّب خط **Cairo** (Black) من Google Fonts. السكربت بيختار أول خط موجود: Cairo → Almarai → Tajawal → Noto Sans Arabic.
3. من Preferences > Type اختار **South Asian and Middle Eastern** عشان العربي يتوصل صح.
4. File > Scripts > Run Script File… واختار `GFX01-build.jsx`.
5. السكربت بيبني كل حاجة جوه فولدر `GFX01_Lindbergh_AFC`، وبيحفظ `GFX01_Lindbergh_AFC-v01.aep` (ومش بيكتب فوق أي نسخة قديمة)، وبيطلع صور معاينة في `previews/` ولوج في `GFX01-log.txt`. لو شغلته تاني بيمسح البناء القديم ويعيده من الأول.

أي أصل ناقص بيتحط مكانه placeholder عليه اسمه، فالتكوين والتوقيت بيبانوا حتى قبل ما الصور توصل.

## التوقيت (30fps، 9 ثواني)
| الوقت | اللي بيحصل |
|---|---|
| 0.00–0.40 | صورة المنصة ملء الشاشة + فلاش نيجاتيف مرتين + هزة خفيفة |
| 0.40–0.95 | الصورة بتصغر وتبقى صورة مطبوعة ببرواز (overshoot ‏3.5%)، والبانل الأحمر الممزّق بيدخل من اليمين وجواه الحشد |
| 0.40–1.40 | الخلفية بتوضح (Focus Pull من 22 لـ 1.5) |
| 0.75–1.25 | **الاسم** «لجنة أميركا أولًا» بيظهر من اليمين للشمال مع blur، وبعده النجوم الحمرا |
| 1.25–2.25 | **1940–1941**: الأرقام بتدخل pop، وآخر رقمين في كل سنة بيلفوا زي العدّاد، والشرطة الحمرا بتطلع ما بين السنتين. جوه الأرقام texture جرايد |
| 1.40–2.40 | خط المسطرة بيترسم من اليمين للشمال، والكيكر الإنجليزي بيدخل بالـ tracking |
| 1.85–2.30 | الملصق بيعمل pop وهو ملفوف شوية |
| 2.40–8.15 | Hold: الكاميرا بتدفع ببطء، والصور بتطفو، والجرين شغال |
| 8.15–8.55 | خروج بورق ممزّق بيمسح الكادر للجرافيك اللي بعده |

كله keyframes، مفيش expressions. فيه markers على التايملاين: IN / TITLE / DATES / HOLD / OUT.
